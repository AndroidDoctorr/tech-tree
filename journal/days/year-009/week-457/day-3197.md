**Pedal run — needle DEAD.** Steady pedalling, magnets sweeping the core, and the needle sat there. Checked leads C/D for continuity — sound. Checked the gap — sound. Re-seated the coil — nothing.

| Diagnosis | Read |
|-----------|------|
| **The trap** | ****A rotating magnet does not make a steady current — it makes an alternating one.** Every pole reverses the direction of the push as it passes |
| **Why the needle lies** | **The needle is a **mechanical** detector. Reverse the current dozens of times a second and it gets shoved both ways faster than it can swing — so it **averages to nothing** and sits still. **Zero deflection is not zero current.**** |
| **The proof** | **Turned the head **by hand, one slow pole at a time**: needle **kicked one way** on the pole approaching · **kicked the other way** as it left · reversed cleanly with reverse rotation **—** **INDUCTION CONFIRMED** |
| **Verdict** | ****The machine works.** The instrument can't see what it makes. This is a **rectification problem**, not a generation problem |

| Fix paths | Read |
|-----------|------|
| **Commutator** *(primary)* | **Split-ring on the shaft + brushes — flips the connection each half turn so the output leaves as **pulsed one-way current** the needle *can* read · brass stock @ FORGE-FASTENER · shaft work @ LATHE-1** |
| **Electrolysis witness** *(cheap cross-check)* | **Leads into acidified water — bubbles gas on **both** electrodes under AC · messy, but it is a **second, independent** proof that current flows** |
| **Not yet** | **Output measurement beyond needle-kick class · no wire gauge for a real coil rebuild · **do not chase volts before the commutator**** |
