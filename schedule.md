## How to read dates

| Track | Example | Use for |
|-------|---------|---------|
| **Day N** | **1094** | Absolute timeline · never resets |
| **Cal-Yn Dk** | **Cal-Y4 D127** | Deadlines · feast · harvest windows |

**Formula:** `Cal-Y2 D(N−237)` for **238 ≤ N ≤ 602**. **Cal-Y3 D(N−602)** for **603 ≤ N ≤ 966**. **Cal-Y4 D(N−967)** for **N ≥ 967**. **Feast eve** @ **Day 237 + 365×(Y−1)**.

**Season phase** keys off **SUN-CAL-1** — see [sun-calendar.md](sun-calendar.md).

**Assistant rule:** Before a hero week, warn if plan crosses a **Hard** deadline in **7–14 days**.
