## Design principles

1. **Nobody solos the tree** — charcoal, lime, salt, smelt, medicine split across people.
2. **Archetypes ≠ stereotypes** — each has ego, grief, humor unrelated to "role."
3. **Struggle is visible** — Jin can't fire; Jim can't kneel; Tom hates heat.
4. **Together = the point** — observers test **cooperation**, not one Ulysses.
5. **Journal echo** — Priya @ Orontes is optional POV anchor, not only hero.
