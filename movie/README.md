# Movie — *Working title TBD*

A feature concept spun off from the [tech-tree speedrun journal](../README.md): humans dropped into prehistory with handheld assistants, racing (or failing) toward a civilizational finish line while an audience learns the rules alongside them.

**Status:** Idea bank · not locked to journal canon · tweak freely

---

## Logline (draft)

Aliens run a covert trial: a handful of random humans wake in the wilderness with only a voice-assistant device and one life each — except death is not permanent. They must rebuild civilization from nothing and reach a threshold the observers define (space? contact? something harder). The audience starts as blind as the players.

---

## Core premise

| Element | Draft |
|---------|--------|
| **Who runs it** | Unseen aliens evaluating whether humanity is ready for first contact — or worth preserving |
| **Players** | **5–12** random humans, different backgrounds, different drop sites globally |
| **Device** | Small handheld assistant — voice, knowledge-on-demand, no magic fabricator |
| **Death** | Respawn at last sleep point; corpse vanishes; no cliff-farming |
| **Win condition** | TBD — e.g. reach orbit / cloning / a beacon / survive N years at tech tier X |
| **Time limit** | TBD — pressure without making the plot absurd |
| **Tone** | Grounded survival + dark comedy + wonder; deaths played for implication, not gore porn |

---

## Audience design

- **Same ignorance as characters** — rules discovered by trial, error, and assistant hints.
- **Thin alien frame** — cold open: observers debate mission parameters; then cut to Earth.
- **Character vignettes** — brief pre-abduction normal life (one per player or paired); then *gone*.
- **On-screen UI sparingly** — e.g. **"Death count: 1"** after first respawn; not a full game HUD.
- **Geography as character** — why this valley, why that river; optional VR/Google-Earth-literate protagonist without breaking the fourth wall in dialogue.

## Relationship to the journal

| Journal | Movie |
|---------|--------|
| One immortal player, Orontes valley, day-by-day realism | Ensemble, global drops, compressed time, dramatized |
| Assistant = DM / co-writer | Assistant = in-world device + possible alien back-channel |
| No other humans unless emergency rule | Other players are **built-in** from the start |

The journal remains the **proof-of-concept** for what one obsessive engineer can do alone. The movie asks what happens when several strangers inherit the same rules and disagree about priorities.
