## `G2-STRUCTURAL-CONCEPT-1` *(decisions d5072 · d5080)*

### Crane vs building — **independent systems**

| System | Frame | Carries |
|---|---|---|
| **Crane runway** | **Dedicated column line** · **steel crane beam** · timber bracing only | **Vertical + traverse load** · **not** wing wythe |
| **Building shell** | **BC-2 block stem** · grouted cores · **closed ring beam** · **timber roof diaphragm** | **Envelope + quake diaphragm** · **self-weight + snow** |

> **Do not hang the crane from the block ring beam.** Tie crane columns to **C-1 footings** and to a **separate runway beam**; **gap or slip joint** at the party wall.

### Materials *(d5080)*

| Element | Choice | Notes |
|---|---|---|
| **Permanent walls** | **BC-2 cast block** | Pit bank · grouted cores |
| **West aisle (until C-2)** | **Timber stud `G2-TEMP-AISLE-WALL-1`** | Not load-bearing |
| **Roof** | **Timber truss / rafter** + **iron straps** | Ridge along **10 m** · **~4 m** span class |
| **Crane columns** | **Steel / built-up `REBAR`** on pad bases | **C-2** — not MS-1 |
| **Fired brick** | **Finish only if desired** | **No brick at grade** — BC-2 |
