# Tools

Individuated kit — each row is a thing you would notice missing. Schema and the routing test are in [index.md](index.md).

`| ID | Tool | Where | State |`

No quantity column: counts ride in the name (`Chisels ×4`), because a set that splits becomes two rows anyway. `State` is the live field and the reason this file exists — a tool's condition is what you need at the moment you reach for it.

Lab glass is here rather than in resources because each piece is individually blown, individually flawed, and not interchangeable.
