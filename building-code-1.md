## BC-1 requirements

### Foundation & floor

| Rule | Standard |
|------|----------|
| **Socle** | **Stone FS perimeter ring** · frost-class · bonded to mure base |
| **Underfloor** | **Gravel + lime bed** (hypocaust plenum optional per wing) |
| **Finish floor** | **Tile TR class** *or* **oak plank** (clean wings / horreum grammar) · mud rooms may use gravel scrape + mat |

### Envelope

| Rule | Standard |
|------|----------|
| **Walls** | **Single-wythe brick mures** (or rubble-lime core where bath grammar demands) · **bond beam** @ head |
| **Roof** | **TR tile** primary · **shingle class** acceptable when **decent TR/reed pitch** proven *(portico · temp sheds)* · drip PASS mandatory |
| **Interior finish** | **Limewash** minimum · **paint** optional @ clean wings |
| **Heat** | **Indirect** — hub plenum / hypocaust stub / wing cheek · **no open hearth in pigment/oil wings** |
| **Vent** | **Ridge hood · louvers · operable shutters** · cross-draft tested where hearth/wet work |

### Windows *(target · interim wood OK)*

| Rule | Target | Interim |
|------|--------|---------|
| **Frame** | **Metal strap casement** · seats in **SEAL-GROOVE / jamb reveal** | **Oak lintel · sill · jamb · batten shutter** |
| **Glazing** | **Glass panes** · KILN-C / GP pane class · lead or oak bead grid | **Open shutter · seal v1** |
| **Seal** | **Hide/wool + reed felt @ groove · M-08 sill/head bead** | **✓ required now** |
| **Shade** | **Awning** @ exterior over each glazed aperture | **Reed/canvas · portico grammar** |

### Doors

| Rule | Standard |
|------|----------|
| **Hardware** | **Brass handle + brass hinges** (iron retired @ clean entries when upgraded) |
| **Seal** | **Weather strip v1** — hide/wool · reed felt · M-08 pitch @ sill · **DOOR-SEAL grammar** |
| **Entry** | **No direct exterior-to-clean-room** — **portico or mudroom airlock** minimum · **coir or woven rug @ threshold** |

### Entry airlock *(portico / mudroom)*

| Element | Required |
|---------|----------|
| **Roof / rain break** | Reed + pitch or tile eave extension |
| **Boot brush / scrape** | Coir mat or equivalent @ threshold |
| **Coat pegs** | Minimum ×2 @ temp portico class |
| **Rug** | **Woven or approved mat** inside threshold *(not coir-only long-term @ clean bay)* |
| **Drain** | Gravel scrape pad · pitch to drain lip |

### Drainage *(filed d1760)*

| Rule | Standard |
|------|----------|
| **Site drain** | **Graded swale or trench** off **every wing cheek** · **≥1–2% fall** to **ditch / D-1 / impluvium** — **no pond @ sill or socle** |
| **Underfloor** | **Gravel + lime bed** must tie into site drain — **not blind basin** |
| **Airlock pad** | **Gravel scrape + pitch out** @ portico/mudroom *(see Entry airlock)* |
| **Spring test** | **Mandatory pour test** each **Cal-Y spring** *(pre-sow band OK)* — **×2 bucket @ lowest cheek + entry pad** · **clear <~2 min · no sill pond** |
| **Maintenance** | **Scrape silt/leaf choke** · **repack gravel** · **widen trench** when test fails |

**Atelier audit d1760:** **E swale belt bend scraped ✓ · pour PASS · recheck @ full spring thaw.**
