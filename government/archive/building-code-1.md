# Building Code 1 *(BC-1)* — archived

**Filed:** Day 1759 · **Cal-Y6 D61** · **Superseded Day 3275**

> ☠ **Do not build to this document.** It is kept for the record only.

BC-1 was written when the materials were **brick, lime mortar, oak and tile**. It predates pozzolanic concrete, iron bar, the gypsum bed at `M-21`, and `GEN-WW-1` — so it has nothing to say about foundations, reinforcement, plaster or services, which is most of what a code is for.
