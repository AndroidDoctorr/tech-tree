## FC-1 requirements

### Wood carcase & joinery

| Rule | Standard |
|------|----------|
| **Stock prep** | **Cut and fit neatly** — measured precisely · square · plane-true faces |
| **Assembly** | **Hide glue** and/or **brass nails** *(WIRE-NAIL-BRASS / furniture nail class)* · iron nails **structural timber only** |
| **Finish order** | **Plane → sand-smooth → assemble → stain (if named) → tallow wipe** · see **WOODCRAFT-FINISH-1** |
| **Edges** | **Beveled or filleted** on show faces — no raw arris @ habit touch zones |
| **Exempt** | Rough structural timbers · hidden joists · field stakes · green splits @ trail |

### Cabinet doors *(frame-and-panel)*

| Rule | Standard |
|------|----------|
| **Frame** | **Stile-and-rail** · mortise/tenon or pinned lap · **filleted internal edges** on the opening |
| **Panel** | **Flat board behind the frame** — field set in groove or rebate · **depth + shadow line** *(modern inset-panel look)* |
| **Fit** | **Even reveal** · no bind · **weather strip** @ exterior entries per BC-1 |

### Metal fixtures

| Rule | Standard |
|------|----------|
| **Hinges · handles · pulls · latches · slides** | **Brass** — cast + file · strap or butt knuckle class |
| **Polish** | **Olive oil wipe** after install · re-wipe @ seasonal care |
| **Iron** | **Strap backing · hidden nail · forge structural only** — not show hinges @ FC-1 targets |
| **Mount** | **Hinge mortises @ DRILL-PRESS-1** · knob/pull turns @ **LATHE-1** when round |

### Stain & oil

| Rule | Standard |
|------|----------|
| **Default** | **Tallow lock** after sand-smooth · optional **OIL-Y7** satin wipe on show desks |
| **Named stain** | **Merlot / madder / player hero** — test swatch before commit · **RECORDS-DESK-1** = reference tier |

## Wet work & counters *(see BC-1)*

**FC-1 does not govern sinks or splash zones.** Those live under **BC-1**:

| Element | Standard *(BC-1 wet supplement)* |
|---------|-------------------------------------|
| **Counter tops** | **High-quality refractory tile** or dressed stone · smooth · flat · **neat lime-sand grout** |
| **Sinks & slops** | **Ceramic or metal** — **not wood** @ wet service |
| **Wall splash** | **Tile splash** behind sinks and slop zones · grouted · ties counter grammar |

**Chem lab:** frame/legs oak · **tops/floor/splash = tile/stone** per [chem-lab-plan.md](chem-lab-plan.md).
