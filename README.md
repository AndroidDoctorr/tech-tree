Every folder's contents are described in an index file. That is the place to start when searching.

**One week = seven days.** Week *N* covers days **(N−1)×7 + 1** through **N×7**, so week `= ceil(day / 7)`. Day files live in `journal/days/year-00Y/week-NNN/`.
