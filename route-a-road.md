## TRAIL-Q scale *(per leg · 0–5)*

Think **Minecraft path grading** — each tier removes friction (deviation, slope, brush, rut, approach stumble).

| **TQ** | Label | **Loaded pace** *(~53–81 kg column)* | What it feels like |
|--------|-------|--------------------------------------|---------------------|
| **0** | **String** | **~2.5 km/h** | Scout tape · bind · sidestep · no crown |
| **1** | **Marked** | **~2.8 km/h** | Stakes/char visible · still rough · frequent adjustments |
| **2** | **Crown** | **~3.2 km/h** | PW crown · one-line wagon track · bridge build grammar |
| **3** | **Pass** | **~3.5 km/h** | Reliable loaded · approaches dressed · minor ruts only |
| **4** | **Haul** | **~3.8 km/h** | Cuts/fills · fell lane · bridge touches · repeat-trip class |
| **5** | **Road** | **~4.2 km/h** | Haul road · minimal deviation · ore-return target |

**Theoretical max** on perfect flat marked crown: **~5 km/h** motivated empty wagon — you are **not there** on Route A yet; slope + crossings cap honest days.

**Hop time** between nodes ≈ `km ÷ loaded_pace` + **crossing minutes** (ford ~15 min · bridge ~25 min).

## Work points *(WP)*

Each **TRAIL-WORK** block on a leg files **+1 WP** on that leg.

| Work type | Needs on wagon | Typical block |
|-----------|----------------|---------------|
| **GRADE** | Mattock · PW string | Crown scrape · terrace step · drain pinch |
| **CLEAR** | Axe · bill | Brush · sapling · overhang · bind cut |
| **FILL** | Stone pinch · barrow | Rut · wash · ford exit line |
| **BRIDGE-TOUCH** | Hammer · wedges · optional lime pinch | Approach apron · lash check · wedge seat |
| **MARK** | Char · M-spike | Re-stake · token refresh |
| **FELL** | Axe | Oak/pine off crown · **only** @ marked lane |

**TQ gain:** **+4 WP → +0.5 TQ** on that leg (round down display OK · track fractional internally). **Cap TQ 5.**

**Doctrine TRAIL-WORK-1 *(filed d1404):* Every ore-trip leg — outbound **or** return — carry **maintenance slice** (tool roll · optional stone/lime from column or HOME margin). **Sacrifice march speed for WP** when calendar allows. **Outbound:** prefer **stone + mortar** for **BRIDGE-TOUCH** heroes. **Return:** GRADE · CLEAR · FILL when stock ×0.
