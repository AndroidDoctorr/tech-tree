# Space crew matrix

*How the cast maps to a **macguffin + launch** ending. Torr = journal POV @ Orontes — **infrastructure engine**, not solo hero.*

**Design rules:**

1. **Every first meeting = instant advantage** — a table-flip unlock, not Act 3 synergy.
2. **Torr leads breadth** (campus · ore · iron · physics) — others **beat him in narrow lanes** @ Year 1–2.
3. **Together ≈ ideal crew** — observers’ hidden score rewards **teaching + trade**, not hoarding.
4. **Endgame:** merged tech → **beacon / probe / archive key** → space travel (**crew of few**, rest on ground).
