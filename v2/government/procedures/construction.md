# Building construction phases


## Phase I - Site selection and surveying
1. Select an appropriate site. Consider size, stability, drainage, wind/fumes, and access

2. Survey the site, determine layout, floorplan, drainage plan, etc.

3. Measure and stake the site

## Phase II - Foundation
1. Level/grade the area

2. Dig out the footprint

3. Place wood forms for foundation

4. Pour foundation

5. Gravel fill

6. Place forms for support columns

7. Insert rebar

8. Pour columns

## Phase III - Masonry
1. Lay bricks, incorporating rebar, leaving doorways and windows

2. Lay bond beams

3. Add hypocausts, hearths, chimneys, and other built-in stonework or fixtures

4. Place forms for pads and portico

5. Pour surrounding pads and portico

6. Add brickwork to portico if applicable

## Phase IV - Roof
1. Lay beams, rafters, and joists

1.5. Install posts/frames for portico(s)

2. Fix battens and add flashing

3. Lay sheathing

4. Seal tiles

5. Lay tiles

6. Add vent covers

## Phase V - Openings
1. Build doors

2. Build window frames

3. Install doors and windows

4. Seal with weather stripping

## Phase VI - Floors
1. Grout tiled floor areas

2. Lay and grout tiles

3. Lay planks

4. Sand and seal floor planks

5. Lay tilework for countertops, backsplashes, etc.

## Phase VII - Walls and fixtures
1. Grout and plaster interior walls

2. Grout exterior walls

3. Build cabinets, shelves, and other built-ins

4. Add moulding and baseboards

5. Add paneling if applicable

6. Paint if so desired

## Phase VIII - Linens
1. Weave rugs, curtains, and awnings

2. Build awning frames and curtain rods

3. Install awnings, hang curtains, place rugs
