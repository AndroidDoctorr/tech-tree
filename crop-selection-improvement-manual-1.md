## Core rules *(hard procedures)*

| Rule | Procedure |
|------|-----------|
| **Elite never mixes** | **Separate jar · separate tag · Y*n* suffix** — thresh elite last on clean cloth |
| **Rogue pull @ green line** | **Lodging · mold · bolt early · shatter · bitter · weak stand** → **cut or pull before pollen/seed set when possible** |
| **Observe before you sow** | **One note per crop per season minimum** — even “no change” counts |
| **Save from best plants only** | **Not from field average · not from tail harvest unless labeled TRIAL** |
| **Hands off WOAD/madder lines** | **Dye/perennial grammar overrides grain drill** |
| **Wild margin ≠ field drill** | **P-07 patch · ditch flax · T-2 lips** — select for **margin hardiness**, not bed uniformity |
| **Orchard pick = selection event** | **Best fruit from **C1–C4** · largest clusters · clean skin** — eat/leather/process · **seed/cutting from winners** |

## Annual crops — target traits *(→ domestic direction)*

| Crop | Select for | Against / rogue |
|------|------------|-----------------|
| **Emmer** | **Non-shatter · plump kernel · uniform height · stiff straw · clean head** | Shatter · mold · lodge · small/chaffy |
| **Lentil (P-17)** | **Upright · full pod · even maturity · high seed count** | Blank pods · early drop · weedy mix |
| **Chickpea (P-18)** | **Stand density · pod fill · drought tolerance @ S bed** | Blight · empty pod · dwarf weak |
| **Field flax (Bed B)** | **Stem length · low branching · even snap ripening · fine fiber** | Short · coarse · uneven ripen |
| **Hemp (Bed A N)** | **Fiber length · thin bark · male/female balance for fiber band · seed only from best stalks if saving** | Woody · branchy · rot @ base |
| **Fava (headland)** | **Pod size · black seed class · nitrogen service without smother** | Small pod · weedy · cross with wild if off-type |
| **Culina herbs** | **Bolt resistance · aroma · leaf yield · true-type seed** | Bolt first · mildew · off scent |
| **Madder** | **Root crimson yield · crown vigor** *(root dig years)* | Weak color · crown rot |
| **WOAD** | **Leaf mass · indigo potential · biennial rosette hold** | Bolt · frost damage · pest strip |
